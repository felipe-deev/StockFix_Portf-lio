# StockFix · Portfólio

Página de demonstração que apresenta o **StockFix**, um ERP para compras, estoque e vendas de pequenas empresas.

Este repositório contém **apenas a apresentação**. O código do sistema fica no repositório do projeto: <https://github.com/felipe-deev/StockFix>.

## Como abrir

Abra o arquivo `Portfolio.html` no navegador. Não precisa instalar nada nem rodar servidor.

## Estrutura

```
Portfolio.html   conteúdo da página
css/style.css    estilos (cores, tipografia, layout responsivo)
js/main.js       simulação de pacotinhos (500 unidades, 20 por pacote)
```

A simulação é local e ilustrativa: não acessa banco de dados nem altera estoque.
